# Contributing

Thanks for contributing to the Nova CLI!

## Build & test

Requires Go (see `go.mod` for the version).

```bash
./build.sh          # builds ./bin/nova (macOS/Linux)
go vet ./...
go test ./...

# podman integration tests (need podman and a local registry, see pkg/docker/podman_integration_test.go)
go test -tags integration -run TestPodman ./pkg/docker/
```

## Commit messages & releases

Releases are fully automatic on merge to `main`, using
[semantic-release](https://semantic-release.gitbook.io/). The version is derived
from [Conventional Commits](https://www.conventionalcommits.org/) in the PR title
(PRs are squash-merged):

| PR title | Release |
|---|---|
| `fix: …` | patch (`0.0.x`) |
| `feat: …` | minor (`0.x.0`) |
| `feat!: …` / `BREAKING CHANGE:` | major |
| `docs:`, `ci:`, `chore:`, `refactor:`, `test:` | none |

Binaries are published to [GitHub releases](https://github.com/wandelbotsgmbh/nova-cli/releases),
the Homebrew tap and winget.

## Generate Catalog Schema

Structs for the [Catalog Schema](https://catalog.wandelbots.io/schema.json) can be autogenerated

```bash
# update the schema if needed
curl -o pkg/catalog/catalog_schema.json https://catalog.wandelbots.io/schema.json
# recreate the schema
go generate github.com/wandelbotsgmbh/nova-cli/pkg/catalog
```

## App Examples

What is an app example?
An app example is a specific app, with a limited use case to show the customer a possible solution design for a problem.
An example can be seen here: [wandelbots-js-robot-visualization](https://github.com/wandelbotsgmbh/wandelbots-js-robot-visualization)

The CLI will fetch the `wandelbotsgmbh` github page for these templates.
```bash
$ nova app example list
+-----------------------------------+--------------------------------+---------------------------------------------------------------------+
|               NAME                |          DESCRIPTION           |                                 URL                                 |
+-----------------------------------+--------------------------------+---------------------------------------------------------------------+
| wandelbots-js-robot-visualization | Template example on how to     | https://github.com/wandelbotsgmbh/wandelbots-js-robot-visualization |
|                                   | show and move a robot          |                                                                     |
+-----------------------------------+--------------------------------+---------------------------------------------------------------------+
```

App examples can be downloaded with the CLI `nova app example get example_name`.

### Providing App Examples

You can create any App project and publish it to github.
Project Naming convention: `wandelbots-your-project-name` (wandelbots might be replaced by `nova` in future).
Mark the project as `template` in Github settings and put the topic `app-example` to it.
That's it.

### Template App Examples

In order to make it easier for people to get started, the CLI can inject some information into the project, while downloading.
Files need to have the ending `.tpl`.
Internally [Golangs templating](https://pkg.go.dev/text/template) package is used.

Following information is available:
```golang
type BasicAuth struct {
	Username string
	Password string
}

type InstanceInformation struct {
	// The host under which the nova api is reachable
	NovaApiHost string
	// Basic Auth credentials for accessing virtual nova instances
	BasicAuth BasicAuth
	// The name of the cell, the plugin should connect with/live in
	CellName string
	// Access token received via oauth
	AccessToken string
}

type ExamplesSpec struct {
	// Informations about remote instances
	InstanceInformation InstanceInformation
}
```

Example to be used:
```bash
# .env.local.tpl
# Local env file will be templated with instance information.
# If the user wants to debug/develop it locally, the app will use these values, to connect to the remote instance.
WANDELAPI_BASE_URL="{{ .InstanceInformation.NovaApiHost }}"
NOVA_ACCESS_TOKEN="{{ .InstanceInformation.AccessToken }}"
```
