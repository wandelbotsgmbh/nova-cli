## nova bootstrap all

Run all bootstrap steps in sequence

### Synopsis

Runs the complete bootstrap sequence:
  1. Create target namespace
  2. Deploy Ember Stack Reflector
  3. Apply pull secrets
  4. Apply service-manager HelmChart CR
  5. Apply system-owner Secret

Requires prior authentication via "nova login", a configured kubectl context,
and --version to specify the service-manager chart version (defaults to latest).

```
nova bootstrap all [flags]
```
